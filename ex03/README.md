Project 00 — Linux + Git + GitHub
A foundational project covering Linux command-line basics, Git, GitHub, and SSH authentication.

Exercises

    ex00 — Terminal Navigation


  

    Navigate directories using pwd, ls, cd, and mkdir.
        Create and document a directory structure.


    ex01 — File Manipulation


  

    Create, copy, rename, and delete files.
        Practice shell scripts and output redirection.


    ex02 — Git & GitHub


  

    Initialize a Git repository.
        Stage, commit, and push files to GitHub.
        Practice Git history and remote repositories.


    ex03 — README & SSH


  

    Create project documentation.
        Document the Git workflow.
        Configure SSH authentication using an Ed25519 key.
